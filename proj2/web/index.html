1.1

Convolutions from scratch

Convolution with four loops and two loops in numpy, zero padded, compared against scipy.signal.convolve2d.

Four loops

 
   def convolutions_scratch_four(image, kernel, mode = "full"):
   """
      image: a 2D array
      kernel: a 2D array 
      padding: set to "full"
      
   Returns:
      output_image: a 2D array of size image_dimensions + kernel_dimensions - 1
   """
   kernel = np.flip(kernel)
   kernel_height, kernel_width = kernel.shape
   image_height, image_width = image.shape
   output_rows, output_columns = image_height + kernel_height -1 , image_width + kernel_width -1
   padded_image = np.pad(image, pad_width = ((kernel_height - 1, kernel_height -1), (kernel_width - 1, kernel_width -1)))
   
   output_image = np.zeros((output_rows, output_columns))
   for i in range(output_rows):
      for j in range(output_columns):
         for i_kernel in range(kernel_height):
            for j_kernel in range(kernel_width):
               output_image[i, j] += padded_image[i+i_kernel, j+j_kernel] * kernel[i_kernel, j_kernel]
               
   return output_image

Two loops


   def convolutions_scratch_two(image, kernel, padding = "same"):
   
   kernel = np.flip(kernel)
   kernel_height, kernel_width = kernel.shape
   image_height, image_width = image.shape
   output_rows, output_columns = image_height + kernel_height -1 , image_width + kernel_width -1
   padded_image = np.pad(image, pad_width = ((kernel_height - 1, kernel_height -1), (kernel_width - 1, kernel_width -1)))
   
   output_image = np.zeros((output_rows, output_columns))
   for i in range(output_rows):
         for j in range(output_columns):
            output_image[i, j] += np.sum((padded_image[i:i+kernel_height, j:j+kernel_width]) * kernel)
   return output_image

2.1

Image sharpening

Unsharp masking: blur, subtract to isolate high frequencies, and add them back scaled by α.

Taj Mahal

kernel9x9
sigma1.5
α1.0

A Gaussian blur averages each pixel with its neighbors and keeps slow changes while smoothing out fast changes in pixel intensity. Subtracting the blurred image from the original leaves the high frequencies. An image looks sharper when its high frequencies are stronger so the unsharp mask adds them back weighted by alpha.

Varying the sharpening amount

By increasing the alpha value in the unsharp mask filter, the sharp detail overlay was a lot more pronounced and kept very fine details. Thus, the result with an increased alpha value is an extremely sharp image, as shown above.

Blur a sharp image, then sharpen it back

The original sharp image doesn't have as pronounced edges, while the re-sharpened image has very pronounced edges. However, the re-sharpened image is generally blurrier for the remainder of the image that is not the edges.

2.2

Hybrid images

Low frequencies of one image plus high frequencies of another. Up close you see one; from far away, the other.

Full process: Derek and Nutmeg

Fourier transforms (log magnitude)

Result

low pass sigma5
high pass sigma3

The cutoff frequency of each filter is set by its Gaussian with the low pass sigma and the high pass sigma, which I tuned separately. I used low pass sigma of 5 (for the low-pass filter on Derek) and high pass sigma of 3 (for the high-pass filter on Nutmeg). A larger low-pass sigma keeps only Derek's general shape. A smaller high-pass sigma keeps only Nutmeg's fine details. Leaving a gap between the two sigmas means the hybrid image illusion is stronger and a given distance isn't contaminated by the other image.

The most important thing I learned

The most important thing I learned from this lecture is how changes in light at different frequencies affect our perception. I'm a biology and computer science double major, so it's really cool to connect how our biology affects how we perceive computerized images, and how we can trick our biology by being able to decode how we see. Thus, it's important that we learn how images are composed of differing frequencies, so we can manipulate them to get the product we want.
